# 墨阅 · 轻量 Markdown 阅读器

一个专注“读”的 Windows 桌面 Markdown 阅读器：单个 exe（约 1.3 MB），启动即读；排版温润舒适，支持自定义主题；阅读进度实时落盘，关掉再开永远回到原处。

![界面](docs/screenshot.png)

## 特点

- **舒适的默认界面**：暖米白纸色、思源宋体正文、居中书名、柔和的引用与表格样式；内置 7 套主题（陶土、夜墨、宣纸、青瓷、雾蓝、深海、玄夜），窗口标题栏颜色随主题同步。
- **自定义主题**：可新建 / 编辑 / 删除主题，15 项颜色实时预览，支持导入导出 JSON；另可调字体（宋体 / 黑体 / 楷体 / 任意已安装字体）、字号、行距、版心宽度、段距、公式大小、两端对齐、段首缩进、中西文间距，以及自定义 CSS。
- **可靠的阅读进度**：
  - 以“源码行号 + 块内比例 + 文本指纹”记录位置，恢复误差在 1 像素以内；
  - 停止滚动 0.35 秒即写盘（持续滚动时至少每 3 秒一次），写盘采用“临时文件 + 原子替换”，任何时刻状态文件都完整；
  - 关闭窗口时再向页面索取最新位置写一次；即使进程被强制结束，也只会丢失最后不到 0.35 秒；
  - 文件被外部修改后自动重新载入，并借助文本指纹回到原来的段落（即使前面插入或删除了内容）；
  - 每个文件独立记录进度和书签，启动时自动打开上次读的文件。
- **完整渲染**：表格、任务列表、脚注、提示块（`> [!NOTE]` 等）、`==高亮==`、前置元数据、代码高亮（含复制按钮）、相对路径图片；数学公式支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 与 ```` ```math ````，错误公式会优雅降级显示源码；文档中的原始 HTML 会被安全净化。
- **大文档也流畅**：解析与公式排版在后台线程完成，正文按章节分块，只排版可见区域；空闲时再测量其余分块，使滚动条与跳转精确。
- **阅读工具**：可折叠、可筛选、自动跟随的目录；书签；全文查找（高亮全部结果）；跳转到百分比；上一章 / 下一章；跳转后可返回；右键复制公式源码；图片点击放大；打印 / 导出 PDF；全屏。

## 实测数据（《削弱无限倍的太极剑盒子》，1.17 MB / 36.5 万字 / 1450 个标题 / 335 个公式 / 31 个表格）

| 项目 | 结果 |
|---|---|
| 解析 + 公式排版（后台线程） | 约 150 ms，公式 0 错误 |
| 冷启动到恢复阅读位置 | 约 1.4 秒（含浏览器内核初始化） |
| 连续滚动 400 帧 | 平均 6.4 ms / 帧，无一帧超过 20 ms |
| 任意位置跳转 | 13 – 61 ms，目标百分比精确命中 |
| 关闭后重开 / 强制结束后重开 | 回到同一段落，误差 < 1 像素 |
| 压力测试：同一文档拼接 5 倍（5.6 MB / 7250 个标题 / 1675 个公式） | 打开约 1 秒，滚动最慢一帧 18 ms |

## 使用

- 双击 `dist\MdReader.exe` 启动；把 `.md` 文件拖进窗口，或按 `Ctrl+O` 打开。
- 设为默认打开方式：在资源管理器中右键 `.md` 文件 → “打开方式” → “选择其他应用” → 浏览选择 `MdReader.exe` → 勾选“始终使用此应用”。
- 已经打开一个窗口时，再打开其他文件会交给这个窗口显示（单实例）。

### 快捷键

| 操作 | 按键 |
|---|---|
| 打开文件 | `Ctrl+O` |
| 查找 / 下一个 / 上一个 | `Ctrl+F` / `Enter`、`F3` / `Shift+Enter` |
| 显示或隐藏侧栏 | `Ctrl+B` |
| 添加书签 | `Ctrl+D` |
| 跳转到进度 | `Ctrl+G`（或点击顶栏百分比） |
| 上一章 / 下一章 | `[` / `]` |
| 返回 / 前进（跳转之后） | `Alt+←` / `Alt+→`，或鼠标侧键 |
| 字号 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0`，或 `Ctrl+滚轮` |
| 切换浅色 / 深色 | `Ctrl+Shift+L` |
| 重新载入 / 全屏 / 设置 / 打印 | `F5` / `F11` / `Ctrl+,` / `Ctrl+P` |

### 数据位置

- 阅读进度、书签与设置：`%APPDATA%\MoYueReader\state.json`（上一次会话的备份为 `state.json.bak`）
- 窗口位置与标题栏配色：`%APPDATA%\MoYueReader\window.ini`
- 浏览器内核缓存：`%LOCALAPPDATA%\MoYueReader\cache`
- **便携模式**：在 `MdReader.exe` 旁边新建一个 `data` 文件夹，以上所有数据都会改存到其中。

运行需要系统自带的 WebView2 运行时（Windows 10/11 默认已安装）。

## 构建

需要 Visual Studio 2022（“使用 C++ 的桌面开发”工作负载）。在项目根目录运行：

```bat
build.cmd
```

脚本会自动生成内嵌资源清单、导入编译环境并输出 `dist\MdReader.exe`。首次构建时会自动下载内嵌浏览器开发包（约 10 MB）到 `third_party\webview2`。`build.cmd` 会以 UTF-8 读取 `build.ps1`，避免中文被系统默认编码误读；全部源文件均为无 BOM 的 UTF-8。

### 开发调试

- 界面（`web` 目录）可在普通浏览器中调试：`python tools/dev_server.py`，然后访问 `http://127.0.0.1:5178/?open=D:/路径/文件.md`。
- 桌面版直接读取磁盘上的界面文件（修改后按 `F5` 刷新即可，无需重新编译）：`MdReader.exe --dev-web=D:\md-reader\web`；`F12` 打开开发者工具。
- `node tools/test_render.js <文件.md>`：在命令行中渲染文档并统计公式错误、残留定界符等。

## 目录结构

```
host/            桌面宿主（C++）：窗口、资源服务、本地文件通道、原子写盘、单实例、文件监视
web/             界面
  js/render/     渲染核心（后台线程运行）：语法扩展、分块排版、目录与统计
  js/reader.js   阅读器核心：分块挂载、高度估算与测量、阅读位置的捕获与恢复
  js/*.js        侧栏、查找、设置与主题编辑器、通用界面组件
  css/           界面样式、正文排版、代码配色
  vendor/        第三方库
tools/           开发服务器、图标生成、渲染自测脚本
third_party/     内嵌浏览器开发包（首次构建时自动下载，不纳入版本库）
```
